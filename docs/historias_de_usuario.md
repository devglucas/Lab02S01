# Histórias do Usuário — Sistema de Aluguel de Carros
### Lab02S01

Formato: **Como** \<papel\>, **quero** \<objetivo\>, **para** \<benefício\>.
Cada história inclui critérios de aceitação (CA) e está alinhada a um caso de uso.

### HU01 — Realizar cadastro

Como cliente, quero me cadastrar no sistema, para poder criar e gerenciar meus pedidos de aluguel.

### HU02 — Autenticar-se

Como usuário cadastrado, quero me autenticar, para acessar as funcionalidades do sistema de forma segura.

### HU03 — Criar pedido de aluguel

Como cliente, quero criar um pedido escolhendo o automóvel e a modalidade (locação, assinatura ou leasing), para solicitar o aluguel de um veículo.

### HU04 — Consultar pedido

Como cliente, quero consultar meus pedidos e seus status, para acompanhar o andamento das solicitações.

### HU05 — Alterar pedido

Como cliente, quero alterar um pedido, para corrigir ou atualizar informações antes da avaliação.

### HU06 — Cancelar pedido

Como cliente, quero cancelar um pedido, para desistir do aluguel quando necessário.

### HU07 — Decidir sobre pedido aprovado

Como cliente, quero decidir se avanço para o contrato após um parecer positivo, para efetivar (ou não) o aluguel.

## Agente (Empresa e Banco)

### HU08 — Consultar pedidos recebidos

Como agente, quero consultar os pedidos recebidos, para selecionar quais avaliar.

### HU09 — Avaliar pedido

Como agente, quero analisar financeiramente e avaliar um pedido registrando um parecer, para aprovar ou reprovar a solicitação.

## Banco (especialização de Agente)

### HU10 — Conceder contrato de crédito

Como banco, quero conceder o contrato de crédito associado a um leasing, para viabilizar essa modalidade de aluguel.
